회귀분석
변수는 개체의 어떤 특징을 나타내는 것
	->연속적인 변수끼리의 관계
-다중회귀 분석(다중 종속 변수,독립변수과 매칭)
-단순회귀 분석(종속 변수,독립 변수과 1:1로 매칭)

종속 변수 : 하나 이상의 독립변수의 변화에 의해 변화가 설명되거나 예측하는 변수
독립 변수 : (예측변수,설명변수) 독립변수는 종속변수에 영향을 미칠 것으로 가정되는 연속형 변수(연속형이 아닐수도 있음 회귀분석이 아닌경우)

패턴을 그래프화 시켜서 식을 만듦
y = ax+b
y가 종속변수
x가 독립변수

y = ax+b+c
y = 종속변수
x = 독립변수
b = 상수 -> x가 0일 때를 대비해서 종속변수의 기준수준(최소치)를 제공함
ㄴ 이유 : 직선/그래프를 그리기 위해서
c = 오차항 -> 변수를 많이 넣어서 오차를 최대한 줄이는데도 불구하고 오차가 남아서 잔차라 함(모형화된 오차) = 오차항
ㄴ순수오차 + 모형화된 오차(모형화 오차: 오차속에서도 패턴을 찾아 하나의 독립변수로 빼 회귀분석 식에 넣는 것)
a = 회귀계수 -> 그래프 기울기 결정


종속변수를 잘 골라 잔차를 최대한 줄이는 게 핵심임(회귀분석)

최소제곱법 : SSE를 최소로 하는 직선 구함
	    ㄴ오차 제곱합을 죄소로 하는 B0,B1을 찾음(실제값 - 예측값을 제곱)
SSE : 적합치에서 반응값의 전체 잔차를 측정

오차항(관찰 X)
완전성 : 모델이 모든 것 포착 X
복잡성 : 데이터 제한 또는 알 수 없는 요인이 결과에 영향 미치는 모든 변수를 모델에 포함 못함
유연성 : 설명할 수 없는 구성요소가 있고 독립변수와 종속변수간의 체계적 관계 포착
통찰력 : 모델에 누락된 부분에 대한 통찰력을 얻을 수 있으며, 개선 및 탐색할 추가변수 제안

오차항 : 모델에 없는 요인으로 인해 발생한 차이

잔차(관찰 O) : 예측이 실제로 관찰한 것과 얼마나 다른지,모델이 경험한  것과 다른 
시간을 일관되게(조건을 다 같다고 퉁친다고 가정한 것) 예측하는 경우 잔차를 조사하면 모델을 이해하고 개선할 수 있음

회귀분석은 독립과 종속에 미치는 영햐을 수학적 식으로 모델링 -> 예측 분석
= 하나의 선을 통해 최소의 잔차를 가지는 모델

회귀분석 종류

회귀분석 과정
1.독립변수,종속변수의 산점도를 그림(데이터에 .을 찍는 그림)
2.산점도를 바탕으로 적절한 회귀모형 선택
3.선택한 회귀모형을 자료로 이용 후 회귀계수 추정(기울기)
4.회귀모혀의 적용이 옳은가 판단(잔차 수치를 보고)



시험 : 오차항,잔차,회귀분석
