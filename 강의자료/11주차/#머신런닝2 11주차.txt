서포트 벡터 머신
양성,음성을 구분하는 최적의 한개의 선을 구하는 게 목표 = 결정선

회귀머신
오차가 제일 적은 선을 구하는 게 목표

로지스틱 모델
임계선을 통한 양성 음성 정하는 게 목표


서포트 벡터 머신(SVM)
예측의 개념이 아닌 가장 집단을 여유 있게 잘 나누는 결정선을 활용해 초평면을 찾는 것

SVM의 학습 방식 : 초평면이 최대화되는 것
SVM의 장점 : 복잡한 고차원의 공간에 해당하는 비선형 경계도 SVM형태로 학습 가능(= 오류 데이터의 영향을 적게 받음 +  복잡한데이터를 단순화시킬 수도 있음 + 데이터 수가 적어도 결정선을 잘 구할 수 있음)
로지스틱,회귀분석에서 범주형 데이터들은 더미화 시켜서 처리하는데 사실 큰 의미가 없음 근데 SVM에서는 범주형 데이터를 적절히 저리할 수 있음

범주형 데이터 : (banna,apple) 선택지가 정해져있고 데이터들이 저 중 하나인 데이터들이 범주형 데이터

서포트 벡터 머신이 사용하는 식
내적(벡터)의 식을 이용
도출된 식은 다중회귀 분석과 유사(오차항만 없음)
y = w1x1+w2x2+w3x3+ ... + B(서포트 벡터머신)
y = B + B1x1+B2x2+B3x3 ... (다중회귀)

서포트 벡터 머신 내적의 대상 및 과정
결정선과 데이터의 거리를 내적으로 계산하는 형식
계산한 결과 중 제일 작은(min)거리가 크면 클수록 좋은 모델임.(= margin, 결정선과 데이터 사이의 공간)

서포트벡터머신의 단점
데이터를 구분하는데에 예외를 두지 않고 결정선을 그림(= Hard margin)
선을 곡선으로 그리는 것(= overfitting(과대적합)이라 하며 너무 해당 데이터 맞춤형 모델이라 다른 데이터에는 부적합할 수 있음)

서포트 벡터머신의 단점 해결한 버전(soft margin classification)
cost hyperparameter 사용(결정선을 정함)

cost hyperparameter로 정한 마진 안에 존재하는 복잡한 데이터는 걍 다 무시함.
= 제끼는 데이터가 많으니깐 과소적합의 문제가 생김.

소프트 마진 클래시피케이션의 문제점 해결한 버전
크사이를 허용(= 어느 정도 에러를 이해해 준다 = 마진 안에 있는 데이터들도 그냥 마진 밖에 있다고 퉁 치고 모델 생성
(Reulrization parameter C = 얼마만큼의 에러를 허용할지 정함)


C값과 gamma의 값으로 모델의 복잡도를 조절함.(C값은 작을수록 모델이 복잡하고 gamma값이 클수록 모델이 복잡)


서포트 벡터머신의 정확도 파악
정밀도와 재현도 차이점을 잘 보기(로지스틱과,서포트 벡터머신의 차이),요소 자체는 동일
