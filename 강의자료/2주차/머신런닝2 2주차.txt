머신런닝2 2주차(시험 X)


데이터 = 육감으로 느낄 수 있는 것들 모두

표본 집단 = 데이터의 집단(현재 활용할 수 있는 데이터)

중심극한정리 = 표본이 많아질수록 정규분포에 가까워짐

보통 일반화하기 위해서 30이상의 표본 필요

귀무가설,대립가설을 결정하는 값 = p-value값
p-value <=0.5 = 대립가설
p-value>0.5 = 귀무가설

대립 = 차이 ㅇ
귀무가설 = 두 개의 데이터들이 차이 X(ex 지구,타행성)

변동성= 분산의 분포로 계산
ㄴ평균의 분포로는 X

변동성이 작을수록 안정

분산분포 계산
-Chi-Squae test : 적합도 검정
	ㄴ기대한 빈도 분포와 관찰한 빈도 분포 비교(기대 빈도분포 = 예상빈도분포)
-Chi-Squae test : 독립성 검정(독립성 : 연관성이 없는 거,하나의 변수를 안다고해서 다른 변수의 결과를 결정할 수 없는 것)
	ㄴA와 B 교차분석으로 독립성 파악

-분산 분석:여러집단에서의 평균과 전체 집단의 평균들을 비교해서 의사소통 결정(행동 결정)
	ㄴ독립변수: 가설의 원인이 되는 변수
	ㄴ종속변수: 가설의 결과가 되는 변수 <-독립변수에 영향 받음
일원 분산분석 : 하나의 	독립변수,한개의 종속변수
이원 분산분석 : 2개의독립변수(명목형,순서형),1개의 종속 변수

추론 통계= 데이터 전체,일부를 분석 = 현상을 파악(예측 X)
머신런닝 = 패턴 학습 후 예측,분류,생성 수행

추론 통계로 데이터의 상관관계 파악 후 그 데이터를 머신런닝으로 활용
